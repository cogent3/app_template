## Installation

### create a virtual environment and activate it

#### Linux or MacOS

```bash
python -m venv .venv
source .venv/bin/activate
```
#### Windows

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
### Install the package

Install the package, using -e to install it in editable mode with the test dependencies.

```bash
pip install -e ".[test]"
```

### test the app

To run the test suite use the following command to validate the app (for python 3.12)

```bash
nox -s test-3.12
```

### See the app working

- load trial_plugins.ipynb from the docs folder into VS Code, and set it to use your venv as the notebooks python interpreter
